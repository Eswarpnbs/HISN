HISN knowledge base: downloads

  1. Click every link below (Safari is fine). Each PDF goes to your Downloads folder. A visited link turns grey.
  2. Files marked check may be a different law than named. That is fine: the script reads each PDF and says what it really is; we keep only relevant ones.
  3. If a link opens a page instead of a file, click the page's download button.
  4. Then in Terminal: python kb/batch_add.py ~/Downloads (dry run, changes nothing) and send the output to Claude.
